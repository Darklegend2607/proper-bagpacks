# Proper Bag Packs (Fabric 1.21.1)

- 6 tiers: leather, copper, iron, gold, diamond, netherite
- Right-click opens, sneak + right-click wears it (chest slot), press B to open the worn one
- Dye + backpack in a crafting grid recolors it (contents are kept)
- Tier upgrade: backpack in the middle of the 3x3 grid, 8 of the next tier's material around it
  (copper ingot, iron ingot, gold ingot, diamond, netherite ingot)
- Stack upgrades (x2, x4, x8, x16) and Auto Feeder upgrade

Build: push to GitHub, open the Actions tab, download the jar from the build artifacts.
